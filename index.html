Standard mode vs Rock-Paper-Scissors mode
Standard mode
Each team avoids squares attacked by any opponent. With 3 teams, everyone avoids everyone else — mutual hostility. Like three armies all simultaneously at war.
RPS mode
Each team only avoids the one team that beats it. Rock can safely sit where Scissors could attack — only Paper is the threat. Creates a cyclic dominance hierarchy.
The RPS avoidance cycle
Rock ← loses to Paper ← loses to Scissors ← loses to Rock
Rock avoids Paper · Paper avoids Scissors · Scissors avoids Rock
Key difference: In standard 3-team mode, each team avoids 2 opponents (higher constraint). In RPS, each team avoids only 1 (lower constraint, more freedom). This asymmetry creates spiral-like territorial patterns instead of the symmetric quadrant structure. Works with any number of teams ≥ 3 in a cycle.
